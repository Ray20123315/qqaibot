# QQ 官方指令選單：移除過期的「设置插话率」

## 已查明

使用者在 QQ 的 AIBot 原生指令選單看到「/!设置插话率」、「查看主动插话暂停状态」，但目前 QQAIBOT 精簡 AI 程式並未註冊這條指令，也不存在「主動插話率」管理功能。最新回歸測試會檢查 `worker.js`、`src/abot-ai.js`、`src/assistant.js` 和 `src/core.js` 不重新註冊這些舊名稱。

**QQ 輸入框由 QQ 客戶端展示的「/」建議並非普通 Bot 回覆文字**。QQ 官方開發文件指出，開發者在機器人管理端的「發布設定 → 功能配置 → 指令配置」新增／移除的指令會顯示於 QQ 群、單聊等原生指令面板。因此只部署 Worker 或在程式裡刪指令，不能保證已發布的舊選單項目消失。

## 必須對 QQ 官方管理端清理

1. 使用 AIBot 對應的 QQ 開放平台開發者帳號登入 [QQ 機器人開放平台](https://q.qq.com/)。
2. 開啟 AIBot 的「發布設定」→「功能配置」→「指令配置」（依新版後台名稱可能略有不同）。
3. 找出名為 `!设置插话率` 或 `设置插话率` 的舊指令，以及說明「查看主动插话暂停状态」的項目。
4. 刪除這條舊指令，只保留新版仍有效且使用者確實需要的入口；按頁面提示確認／重新發布。
5. QQ 客戶端重新進入聊天、重新開啟指令建議，確認舊指令不再出現。若仍在，檢查其他「指令面板」或「快捷選單」配置和客戶端快取。

這是 QQ 開放平台**發布資料**的管理動作，目前沒有已連線的 QQ 官方後台操作工具，也未核對到該筆發布資料的 ID，因此不能聲稱已從平台刪除。不要因這條過期指令去修改 Bbot 群設定、AI 模型、Secret 或 D1。

參考：QQ 官方 `tencent-connect/bot-docs` 的「發布設定 / 功能配置 / 指令配置」說明，以及 QQ 指令面板管理 API。
